# Marginalia — E-Library (Nuxt 3 + TypeScript + Tailwind)

A digital library catalog built in Nuxt 3 / TypeScript, styled with
Tailwind CSS. Structurally inspired by RULE Library (the Royal
University of Law and Economics' digital catalog) — a search-first
catalog with rich, OPAC-style detail records — with entirely
original content and a different visual theme.

**No hand-written CSS.** Every design token (colors, fonts, radius,
shadows) lives in `tailwind.config.ts`, and every page/component is
styled with Tailwind utility classes directly in the template. There
is no `assets/css` folder and no `<style>` blocks in any `.vue` file.

## Pages

- `/` — Search-first hero, "browse by subject" tiles, features, testimonials, newsletter signup
- `/products` — Full catalog: sidebar filters (subject + level), search, sort, book grid
- `/products/[id]` — Rich catalog record: cover, availability, save/borrow actions, a facts
  panel (call number, ISBN, publisher, edition, language, format, file size, reading time),
  subject-heading chips, and tabs for **Description**, **Table of Contents**, **Reviews**
  (with a rating breakdown), and **Cite this** (auto-generated APA citation)
- `/about` — Vision, mission, stats, services, contact
- `/account` — Mock profile, reading stats, saved/favorite books
- `/login` — Login form with client-side validation

## Data

`data/books.json` is a fake but rich dataset — 21 books with full
metadata: descriptions, table of contents, tags/subjects, call
numbers, ISBN, publisher, edition, language, format, file size,
reading time, ratings, and multiple reviews per book.

It's generated by `scripts/generate-books.mjs` (a one-off Node
script, not part of the running app) — edit the `base` array there
and re-run `node scripts/generate-books.mjs` to regenerate the JSON
with new fake data.

`data/books.ts` is a typed loader over the JSON — it imports
`books.json`, exports the `Book`/`Review`/`Availability` interfaces,
and a few helpers (`getBookById`, `getRelatedBooks`,
`availableCopies`, `formatYear`).

## Structure

```
components/           AppHeader, AppFooter, BookCard, CategoryChips, StarRating
data/books.json        fake catalog dataset (21 books, rich metadata)
data/books.ts           typed loader + helpers over books.json
scripts/generate-books.mjs   regenerates books.json
pages/                  index, products/index, products/[id], about, account, login
tailwind.config.ts       all design tokens (colors, fonts, radius, shadows)
```

## Routing

`/products` uses Nuxt's file-based dynamic routing:

```
pages/products/index.vue   ->  /products
pages/products/[id].vue    ->  /products/:id   (e.g. /products/9)
```

`[id].vue` reads `route.params.id`, looks the book up via
`getBookById()`, and throws a real 404
(`createError({ statusCode: 404, fatal: true })`) if no book
matches — try visiting `/products/999`.

## Next steps if you want it fully functional

- Replace `data/books.json` with a real API or database (e.g. a
  Nuxt server route + SQLite/Postgres, or a headless CMS).
- Wire up `/login` and `/account` to real authentication
  (nuxt-auth-utils or better-auth work well with Nuxt 3).
- Deploy to Vercel or Netlify (both support Nuxt 3 out of the box).
